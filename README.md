# Words Memory - 单词记忆系统

![Words Memory Logo](assets/images/logo.svg)

Words Memory是一款精美的单词记忆系统，采用Apple Design风格，结合毛玻璃磨砂效果，帮助用户高效记忆和学习单词。

## 特点

- 🎨 精美的Apple Design风格界面
- 🔍 毛玻璃磨砂效果，视觉体验舒适
- 📱 响应式设计，同时支持桌面端和移动端
- 🧠 基于艾宾浩斯遗忘曲线的科学记忆算法
- 📊 详细的学习统计和进度追踪
- 💾 本地存储，无需联网即可使用

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage API

## 功能模块

1. **单词库管理**：导入、创建和管理您的单词库
2. **记忆学习**：科学的记忆方法，提高学习效率
3. **智能复习**：根据遗忘曲线，自动安排复习计划
4. **学习统计**：跟踪学习进度，激发学习动力

## 快速开始

1. 克隆本仓库到本地
2. 使用浏览器打开`index.html`文件
3. 点击"开始使用"按钮，进入应用
4. 选择一个单词库，开始学习

## 使用说明

### 单词库管理

- 系统自带两个示例单词库：初级英语和商务英语
- 您可以创建自己的单词库，添加需要学习的单词
- 每个单词可以包含：单词、释义、音标、例句等信息

### 学习模式

- 选择单词库，开始学习新单词
- 查看单词，点击卡片翻转查看释义
- 根据记忆情况，选择"困难"、"一般"、"简单"或"已掌握"
- 系统会根据您的反馈，调整单词的复习计划

### 复习模式

- 系统会根据记忆算法，自动安排需要复习的单词
- 复习时，同样可以对记忆情况进行反馈
- 记忆级别达到最高级时，单词将被标记为"已掌握"
