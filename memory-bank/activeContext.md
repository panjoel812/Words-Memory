# Words-Memory 活动上下文

## 当前工作重点
已根据UI设计图完成单词记忆系统的静态网站基础架构，成功实现了以下功能：
1. 创建了符合Apple Design风格的UI界面
2. 实现了毛玻璃磨砂效果的视觉设计
3. 开发了响应式布局，适应电脑端和手机端
4. 应用了蓝色主题色设计整体界面
5. 实现了基本的单词记忆和学习功能
6. 重构了学习界面，实现了单词卡片翻转效果

当前正专注于提升用户学习体验，优化界面交互效果，特别是单词卡片的记忆模式。

- 增加了学习进度和得分统计功能

## 活动决策和考虑
### 设计决策
- 采用了纯前端静态网站，所有数据通过localStorage本地存储
- 使用了BEM命名规范组织CSS样式
- 采用模块化设计组织JavaScript代码
- 使用SVG图标，减少图片资源加载
- 从传统的多卡片列表切换到单卡片翻转模式，提升学习专注度
- 采用卡片翻转动画增强用户交互体验

### 技术考虑
- 已处理Safari浏览器的毛玻璃效果兼容性，添加了-webkit-backdrop-filter
- 优化了移动端触控体验，提供了专门的移动端导航栏
- 实现了基于艾宾浩斯遗忘曲线的记忆算法
- 使用CSS 3D转换实现卡片翻转效果
- 采用随机算法生成选项，提升学习挑战性
