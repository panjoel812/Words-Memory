# Words-Memory 系统架构与模式

## 整体架构
Words-Memory采用前端静态网站架构，通过HTML、CSS和JavaScript实现全部功能，无需后端服务。数据存储利用浏览器的localStorage进行本地持久化。

## 核心组件
1. **单词库模块**：管理单词数据，支持分类、导入导出功能
2. **记忆模块**：实现记忆算法，安排学习计划
3. **UI组件**：封装统一的界面元素，确保视觉一致性
4. **响应式布局系统**：适配不同设备屏幕

## 设计模式
- **模块化设计**：各功能模块独立封装，降低耦合度
- **状态管理**：集中管理应用状态，确保数据一致性
- **观察者模式**：UI与数据变化响应式更新
- **策略模式**：支持多种学习策略切换

## 数据模型
1. **单词模型**：
   ```json
   {
     "id": "唯一标识",
     "word": "单词",
     "meaning": "释义",
     "examples": ["例句1", "例句2"],
     "tags": ["标签1", "标签2"],
     "memoryStatus": {
       "level": 0,
       "nextReview": "时间戳"
     }
   }
   ```

2. **学习计划模型**：
   ```json
   {
     "id": "计划ID",
     "name": "计划名称",
     "wordLists": ["列表ID1", "列表ID2"],
     "dailyGoal": 50,
     "progress": {
       "learned": 0,
       "mastered": 0
     }
   }
   ```

## 交互流程
1. 用户登录/注册 → 进入主界面
2. 选择/创建单词列表 → 开始学习
3. 记忆卡片展示 → 用户反馈记忆程度
4. 系统记录学习数据 → 调整下次复习时间
5. 展示学习统计和进度
