# Words-Memory 技术上下文

## 开发技术栈
- **HTML5**：构建网页结构
- **CSS3**：实现界面样式，包括毛玻璃效果和Apple Design风格
- **JavaScript (ES6+)**：实现交互功能和业务逻辑
- **LocalStorage API**：本地数据存储

## 设计规范
### 颜色系统
- **主题色**：蓝色 (#007AFF)
- **背景色**：浅灰色 (#F5F5F7)
- **文本颜色**：深色 (#333333)
- **强调色**：蓝色的不同色调

### 字体系统
- **主字体**：San Francisco (苹果系统字体)，降级为 `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`
- **标题字体大小**：24px-32px
- **正文字体大小**：16px
- **小字体大小**：13px

### 组件设计
- **卡片**：圆角矩形，轻微阴影，毛玻璃效果背景
- **按钮**：圆角，过渡动画，悬停效果
- **导航**：顶部/底部固定，响应式调整
- **输入框**：简约风格，聚焦高亮效果

## 响应式设计
### 桌面端 (>= 1024px)
- 宽屏布局，多列展示
- 侧边导航栏
- 丰富的悬停交互

### 平板端 (768px - 1023px)
- 适度调整布局，减少列数
- 保留部分桌面端交互

### 移动端 (<= 767px)
- 单列垂直布局
- 底部导航栏
- 触摸优化交互
- 隐藏次要功能，专注核心体验

## 性能优化
- 图片资源优化：使用SVG图标和WebP格式图片
- 代码分割：按需加载JavaScript模块
- 缓存策略：合理利用浏览器缓存
- 响应式图片：根据设备提供适当分辨率图片
