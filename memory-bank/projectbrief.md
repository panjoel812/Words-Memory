# Words-Memory 项目简介

## 项目概述
Words-Memory是一款精美的单词记忆系统，旨在帮助用户高效记忆和学习单词。系统采用Apple Design风格，结合毛玻璃磨砂效果，主题色为蓝色，提供流畅美观的用户体验。

## 核心目标
- 提供简洁高效的单词记忆界面
- 支持多种记忆学习模式
- 适应电脑端和手机端不同设备
- 营造愉悦的学习体验

## 主要功能
1. 单词库管理与浏览
2. 智能记忆与复习系统
3. 学习进度追踪
4. 个性化学习计划

## 技术要求
- 前端：HTML5, CSS3, JavaScript
- 设计风格：Apple Design，毛玻璃磨砂效果
- 响应式设计：适配桌面和移动设备
- 主题色：蓝色
